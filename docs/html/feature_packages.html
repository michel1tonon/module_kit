Feature packages (monorepo)

Each feature is an independent Dart/Flutter package. The app shell composes them; integration between features uses OnRamp contracts in a small shared package — never feature-to-feature imports.

Dependency rule: checkout_feature may depend on app_contracts, but must not depend on select_country_feature. The shell registers each feature's *OnRampImpl through FeatureModule.injectors.

Package map

monorepo/
├── packages/
│   ├── my_app/                      # App shell (composition root)
│   │   ├── pubspec.yaml             # depends: module_kit, app_contracts,
│   │   └── lib/main.dart            #          checkout_feature, select_country_feature
│   │
│   ├── app_contracts/               # Shared boundaries only (no UI)
│   │   ├── pubspec.yaml             # depends: module_kit, flutter
│   │   └── lib/on_ramp/
│   │       └── select_country_on_ramp.dart
│   │
│   ├── select_country_feature/      # Owner of select-country capability
│   │   ├── pubspec.yaml             # depends: module_kit, app_contracts
│   │   └── lib/
│   │       ├── select_country_module.dart
│   │       └── on_ramp/select_country_on_ramp_impl.dart
│   │
│   └── checkout_feature/
│       ├── pubspec.yaml             # depends: module_kit, app_contracts (not select_country)
│       └── lib/
│           ├── checkout_module.dart
│           └── checkout_controller.dart   # uses SelectCountryOnRamp only
│
└── melos.yaml / workspace pubspec   # optional tooling

Evolution path

  1. Local folders — same boundaries under lib/features/ and lib/shared/on_ramp/.
  2. Workspace packages — move each folder to packages/*_feature without changing FeatureModule or OnRamp contracts.
  3. Publish separately — internal pub server or git deps; contracts package stays thin and stable.

What stays inside each feature package

  • Routes contributed by FeatureModule.routers.
  • DI registrars from FeatureModule.injectors.
  • Presentation, domain, data — not exported to sibling features.
  • *OnRampImpl only when this package owns that capability.
